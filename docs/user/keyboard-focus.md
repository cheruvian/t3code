# Keyboard focus

The command palette keeps focus while open. Closing it returns focus to the composer.
While the palette or model picker is open, number shortcuts select its entries instead of
switching threads. Model shortcuts work in Settings as well as the composer.
See [Keybindings](./keybindings.md) to customize these shortcuts.

If you return to typing while a terminal is starting, the composer keeps focus when the terminal
becomes ready. Opening or switching to a terminal explicitly still focuses it.

Press **Ctrl+F** or **Cmd+F** to search loaded messages in the current thread. Search can
reveal messages in folded turns. Load earlier history to include older messages. Use
**Enter** for the next matching message, **Shift+Enter** for the previous one, and
**Escape** to close search.

When the Browser page has focus, the same shortcut searches that page instead. In the
desktop app, pinch on the trackpad to zoom the Browser page or the main chat view.
Browser pages fill the panel by default; choose **Fill** under
**Settings → Integrations → Browser → Default viewport** to reset a saved device size.
